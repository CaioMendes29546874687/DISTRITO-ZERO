# Avisos de licença e dados

## Código do projeto
O código original deste repositório não possui, neste momento, uma licença de código aberto concedida. Não presuma que terceiros podem copiar, modificar ou redistribuir o projeto.

## OpenStreetMap
Se dados do OpenStreetMap forem usados, a atribuição exigida deve ser apresentada, por exemplo: “© OpenStreetMap contributors”, com referência à licença ODbL. A forma de distribuição de bases derivadas deve ser avaliada para cumprir a ODbL.

Informações: https://www.openstreetmap.org/copyright

## Mapas, imagens e modelos 3D
Cada provedor possui termos próprios. Verificar permissão de uso comercial, cache, armazenamento, atribuição, limites de requisição e redistribuição antes de integrar dados ao jogo.

## Conteúdo de terceiros
Não incluir assets, marcas, mapas proprietários, imagens de satélite ou conteúdo de outros jogos sem autorização/licença compatível.
