# Roadmap e critérios de aceite

## Etapa 0 — Fundação (em andamento)
- [x] Criar repositório privado.
- [x] Registrar visão, arquitetura e limites técnicos.
- [x] Criar protótipo web cartográfico inicial.
- [ ] Confirmar que o protótipo abre no Android.
- [ ] Validar atribuição e cobertura dos dados.

## Etapa 1 — Prova geográfica
- [ ] Selecionar uma pequena área de teste.
- [ ] Validar ruas e edifícios com fontes permitidas.
- [ ] Medir consumo de dados, memória e tempo de carregamento.
- [ ] Definir pipeline de conversão para Unreal.

**Aceite:** área de teste carrega de forma repetível, sem travamentos, com atribuição visível e limites de cache.

## Etapa 2 — Protótipo jogável
- [ ] Projeto Unreal configurado.
- [ ] Personagem em terceira pessoa.
- [ ] Alternância para primeira pessoa.
- [ ] Um veículo dirigível.
- [ ] Colisão e interação com alguns edifícios.

**Aceite:** build executável testada em hardware definido, com desempenho medido.

## Etapa 3 — Sistemas de vida
- [ ] Inventário e personagem persistente.
- [ ] Primeira profissão e missão.
- [ ] Economia de teste no servidor.
- [ ] Propriedade com interior modular.

## Etapa 4 — Multiplayer regional
- [ ] Login e sessões.
- [ ] Servidor dedicado de teste.
- [ ] Persistência e proteção contra duplicação.
- [ ] Testes de carga e segurança.

## Etapa 5 — Expansão
- [ ] Mais cidades e países.
- [ ] Transporte terrestre, marítimo e aéreo.
- [ ] Empresas e produção.
- [ ] Clima regional e ciclo de dia/noite.
- [ ] Otimização Android/PC/tablet.

## Regra de qualidade
Uma tarefa só muda para concluída depois de existir implementação, teste reproduzível e evidência do resultado. Documentação e imagens conceituais não contam como funcionalidade implementada.
